# KIA 提成计算器（iPhone 网页 App）

一个能在 iPhone 上当 App 用的提成计算器。单个 `index.html` 文件，离线可用，数据存在手机本地。

## 算法
```
我的提成 = 提成比例 × ( LUX份数×单价 + Greenway + 车架利润 + Trade差价 )
Trade差价 = Trade实际价值 − 折抵给客户的价
```
默认参数：LUX $50/份、Greenway $2995、提成比例 25%（App 里可改，自动保存）。

## 怎么装到 iPhone（变成桌面图标）
**方法一：有网址（推荐）**
1. 把 `index.html` 发布成一个网址（GitHub Pages / 任意静态托管都行）
2. iPhone 用 **Safari** 打开这个网址
3. 点底部「分享」按钮 → **添加到主屏幕**
4. 桌面就多了个图标，点开全屏运行，像 App 一样；之后**离线也能用**

**方法二：直接用文件**
- 把 `index.html` 用邮件发给自己 / 存到「文件」或 iCloud Drive，用 **Safari** 打开即可使用。

## 用法
- 顶部「参数设置」点开可改 LUX 单价、Greenway 价格、提成比例
- 「新增成交」填客户/车型、LUX 份数、车架利润，开关选 Greenway / 有没有置换
- 下方实时显示**这单提成**，点「保存」入账
- 「汇总」看总单数、我的总提成、店总利润、平均每单
- 改了参数，所有历史记录会按新参数自动重算

> 注：这是网页 App（PWA），不是 App Store 上架的原生 App。功能体验对算提成来说没差别。
