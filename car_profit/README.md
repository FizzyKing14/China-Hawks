# 车辆买卖利润表 🚗

自己倒车卖（进车 → 卖车赚差价）用的利润计算表格。

## 文件
- `车辆利润表.xlsx` —— 直接用 Excel / WPS / 手机表格打开就能用
- `build_excel.py` —— 重新生成表格的脚本（`python3 build_excel.py`，需要 `pip install openpyxl`）

## 怎么用
1. **黄色格子**自己填：进车价、修车/翻新、运费、过户/上牌/检测、其他杂费、卖出价
2. **绿色格子**自动算：总成本、利润、利润率、ROI、状态
3. **卖出价留空** = 这台车还没卖出，状态显示「在售」；填上就变「已售」
4. 最下面**汇总区**自动统计：总台数、已售/在售、已售总利润、平均每台利润、整体 ROI、在售占用资金

## 算法
```
总成本 = 进车价 + 修车/翻新 + 运费 + 过户/上牌/检测 + 其他杂费
利润   = 卖出价 − 总成本
利润率 = 利润 / 卖出价
ROI    = 利润 / 总成本
```

默认建好 60 行空白，不够就照着公式往下拖，或改 `build_excel.py` 里的 `DATA_ROWS` 重新生成。
