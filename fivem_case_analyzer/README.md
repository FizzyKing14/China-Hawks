# 圣安地列斯州 · 案件罪名分析器 (FiveM RP)

给 FiveM 角色扮演服用的**离线 Excel 算罪工具**。把一个 case 里每个人做了什么填进去，
自动按《圣安地列斯州刑法典》匹配罪名、合计刑期与罚款、算出建议保释金，并指出主要责任方。

## 文件

| 文件 | 说明 |
|---|---|
| `圣安地列斯州_案件罪名分析器.xlsx` | **直接用这个**。手机 WPS / Excel、电脑 Excel 都能开，纯公式、不联网。 |
| `build_workbook.py` | 生成上面那个表的脚本。改了罪名数据后 `python build_workbook.py` 重新生成。 |

## 怎么用

1. 打开 xlsx，进「**算罪台**」页。
2. 把当事人甲/乙/丙各自的行为填到黄色框里（一个人就只填甲）。
   - 尽量用法典里的词：抢劫、袭警、拒捕、开枪、逃跑、持枪、贩毒、绑架……命中率更高。
3. 下方自动出：命中罪名、罪名数、合计刑期(月)、合计罚款、建议保释金，以及主要责任方。

## 计算规则（来自法典）

- 时间换算：**1 年 = 12 个月 = 12 分钟**。
- 数罪叠加、罚款累计，但**总刑期上限 5 年(60 个月)**，同一罪名不重复并罚。
- **建议保释金 = 刑期(月) × 罚款 ÷ 6**。
- 正当防卫 / 堡垒原则 / 未遂 / 同谋 / 教唆 / 从犯 / 包庇(≤50%)、分级罪名等需人工复核，详见表内「使用说明」页。

## 自己改

- 改罪名/刑期/罚款 → 「罪名表」页。
- 加关键词 → 「关键词表」页（A列关键词、B列对应罪名，罪名要和「罪名表」里一字不差）。

> ⚠ 仅辅助参考，最终定罪量刑以服务器法官 / 司法部裁量为准。

## 覆盖范围

已录入法典第二章~第十一章全部 61 条罪名（人身、财产、公共道德、司法公正、公共秩序、
热武器管制、公共安全/毒品、洗钱身份盗用等），335 个匹配关键词。
注意：本法典**不含交通类罪名**（超速/闯红灯等），故这类描述不会出结果，属正常。
