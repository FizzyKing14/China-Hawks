# 圣安地列斯州 · 案件罪名分析器 — Windows 软件版

和 Excel 同一套数据，做成可双击运行的桌面程序。四个标签页：

1. **算罪台** — 每个人一句话，边打边自动出：刑事罪名 + 刑期/罚款/保释金、内务违规、服务器RP违规，并指出主要责任方。
2. **医疗费用计算器** — 填数量自动算总价。
3. **罪名速查** — 全部罪名搜索（支持按关键词/罪名/说明搜）。
4. **规章速查** — 警务/医护内务处分、服务器违规处罚、黑吃黑、宪法/司法要点。

## 怎么拿到 exe

### 方式 A：云端自动打包（不用装任何东西，推荐）
本仓库已配好 GitHub Actions：
1. 进 GitHub 仓库 → **Actions** 标签 → 左侧选 **Build Windows EXE**。
2. 点 **Run workflow**（或它在每次改动后会自动跑）。
3. 跑完后进入这次运行页面，最下方 **Artifacts** 里下载 `案件罪名分析器-windows`，解压得到 `案件罪名分析器.exe`，双击即用。

### 方式 B：本地打包（电脑已装 Python）
在 `fivem_case_analyzer` 文件夹里双击 **`build_exe.bat`**，完成后 exe 在 `dist\` 里。

### 方式 C：直接用 Python 跑（开发/调试）
```bash
python app.py
```
> 依赖：Python 3.9+（Windows 自带 tkinter）；数据来自 `build_workbook.py`，需要 `openpyxl`。

## 想改内容
所有罪名/关键词/价格/规章都在 `build_workbook.py` 里（软件和 Excel 共用）。改完重新打包即可。
